## 🎯 Objetivo do projeto

O FocusDay foi desenvolvido com o objetivo de aprender e praticar Python na prática, aplicando os conhecimentos adquiridos em um projeto próprio. A ideia foi criar um aplicativo de organização da rotina e foco nos estudos, explorando também o desenvolvimento de interfaces e o armazenamento de dados.

## 🤖 Uso de Inteligência Artificial

Durante o desenvolvimento, utilizei ferramentas de Inteligência Artificial como apoio ao processo:

- **ChatGPT:** auxílio no planejamento geral do projeto, organização das etapas de desenvolvimento, estruturação das funcionalidades e orientação durante o processo.
- **Claude:** auxílio na elaboração e no desenvolvimento do código.

As ferramentas foram utilizadas como recursos de apoio ao aprendizado e à construção do projeto, contribuindo para explorar novas soluções e compreender melhor as etapas do desenvolvimento.

O FocusDay faz parte da minha jornada de aprendizado em Ciência da Computação e da construção do meu portfólio na área de tecnologia.

🚀 Como executar localmente

Pré-requisitos

Python instalado.

Git instalado.

Visual Studio Code ou outro editor de código.

Instalação

Clone este repositório:

git clone https://github.com/SEU-USUARIO/FocusDay.git

Entre na pasta do projeto:

cd FocusDay

Crie um ambiente virtual:

python -m venv .venv

Ative o ambiente virtual no Windows com Git Bash:

source .venv/Scripts/activate

Instale as dependências:

pip install -r requirements.txt

Execute o aplicativo:

flet run main.py

Para testar a versão web localmente:

flet run --web main.py

🌐 Como acessar online

Aplicativo: link de acesso será adicionado após a publicação no GitHub Pages.

O objetivo é disponibilizar o FocusDay gratuitamente pelo navegador, sem exigir cadastro dentro do aplicativo.

Os dados são armazenados localmente no navegador de cada usuário. Por isso, não são compartilhados entre usuários e podem ser perdidos se os dados do site forem apagados.

FocusDay/
